MY SPORTS - ANDROID STUDIO PROJECT

This is a Kotlin + XML starter project based on your Blackboard screenshot.

FEATURES
- Purple toolbar with the current page title
- Bottom navigation: Home, Account, Profile, My Sports
- Home opens with the centered text "Home Fragment"
- My Sports opens a list of sports
- Selecting Football, Basketball, Volleyball, or Tennis opens a secondary sport page
- Android back button returns from a sport page to My Sports

OPEN IN ANDROID STUDIO
1. Download and extract MySportsApp.zip.
2. Open Android Studio.
3. Choose File > Open and select the extracted MySportsApp folder.
4. Allow Gradle sync to finish. Android Studio may ask to install Android SDK 35.
5. Choose an emulator or connect an Android phone, then press Run.

NOTE
This is a starter implementation of the layout and navigation shown in the screenshots. Account, Profile, and individual sport pages are placeholders that you can customize for your activity.
